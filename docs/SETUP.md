# Setup

Nothing to configure: no API key, no Google Cloud project, no account in StreamShell itself.

1. Install the APK (allow installs from your file manager/browser if Android asks).
2. Open StreamShell. On Android 13+ it asks for notification permission the first time media keeps playing in the background; allow it to see the playback controls (playback itself also works without).
3. Sign in: start page > "Sign in to Google", or open youtube.com and use its sign-in button.
4. Optional: make StreamShell your default browser (Android Settings > Apps > Default apps > Browser) so links from other apps open in it.

If Google shows "This browser or app may not be secure" during sign-in, see `KNOWN_LIMITATIONS.md` (Sign-in).
